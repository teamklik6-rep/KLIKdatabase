# Tippo — Referral tiers animation (You → Tier 1 → Tier 2)

Animated version of the referral infographic from the Home page
(Figma «Tippo Website» → Home v2 Desktop 1920, node `734:18948`, 874×210;
mobile layout from Home — Mobile 390, 350×92).

## Files

| File | What |
|---|---|
| `tippo-referral-tiers.js` | Standalone widget (no dependencies). Builds an SVG, drives it with `requestAnimationFrame`; every frame is a pure function of time, so it is seek-able. Picks the desktop or mobile layout from the container width (`< 480 px` → mobile) and switches live on resize. |
| `preview.html` | Both layouts side by side with play / pause / restart and a scrubber. |
| `lottie/tippo-referral-tiers-desktop.json`, `lottie/…-mobile.json` | Same animation as Lottie (30 fps, 210 frames), generated by `../tippo-referral-tiers-animation-src/lottie.py`. No drop shadows (Lottie renderer support is partial). |

Sources: `../tippo-referral-tiers-animation-src/` — `lottie.py` (Lottie export), `capture.mjs` (renders preview frames with Playwright for QA).

## Embed

```html
<div id="referral-tiers" style="max-width:874px"></div>
<script src="tippo-referral-tiers.js"></script>
<script>
  const anim = TippoReferralTiers.mount(document.getElementById('referral-tiers'), {
    variant: 'auto',   // 'auto' | 'desktop' | 'mobile'
    loop: true,
    autoplay: true,
    bg: '#FFFFFF',     // page background behind the graphic (halo of the reward dot)
  });
  // anim.play(); anim.pause(); anim.restart(); anim.seek(2.5); anim.destroy();
</script>
```

The container keeps the layout's aspect ratio (`874 / 210` or `350 / 92`). Font: inherits
`"Non Bureau", Inter, system-ui` — load Non Bureau on the page. `prefers-reduced-motion: reduce`
shows the final static frame.

Lottie: `lottie.loadAnimation({ container, path: 'lottie/tippo-referral-tiers-desktop.json', loop: true })`.

## Timeline (loop 7.0 s)

| Time (s) | What happens |
|---|---|
| 0.00–0.50 | **You** pops in (scale 0 → 1.06 → 1), label «You» fades up (0.30–0.70). |
| 0.50–1.05 | Arrow 1 draws left → right, head scales in at the end; «INVITES» fades in (0.75–1.10). |
| 1.05–1.75 | **Tier 1**: three avatars pop in one after another (every 0.17 s, 0 → 1.10 → 1); label (1.45–1.85). |
| 1.80–2.35 | Arrow 2 draws; «INVITES» (2.05–2.40). |
| 2.35–2.95 | **Tier 2**: the orbit ring draws clockwise from the top. |
| 2.55–3.45 | Six members pop in clockwise (every 0.12 s, 0 → 1.12 → 1); label (3.05–3.45). |
| 3.70 and 4.75 | **Reward waves** (two per loop): a green dot leaves Tier 2 (ring pushes 1 → 1.07 → 1, 0.43 s), travels along arrow 2 right → left (0.5 s), dives under Tier 1 (pause 0.16 s; Tier 1 pulses 1 → 1.065 → 1, 0.6 s), continues along arrow 1 into You. You «breathes» 1 → 1.045 → 1 (1.0 s) and emits a ring ×1.46 (mobile ×1.25), opacity 62 → 0 % (1.0 s). |
| 6.45–6.95 | Whole scene fades out, loop restarts. |

Static frame for the site (= the Figma illustration): any moment in 3.45–3.70 or 5.95–6.45.
