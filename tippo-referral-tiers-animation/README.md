# Tippo — Referral tiers animation (You → Tier 1 → Tier 2)

Animated version of the referral infographic from the Home page
(Figma «Tippo Website» → Home v2 Desktop 1920, node `734:18948`, 874×210;
mobile layout from Home — Mobile 390, 350×108).

**The scene is static — identical to the Figma illustration. Only the dots move, along the arrows
in the arrows' direction: You → Tier 1 → Tier 2, left to right.**

## Files

| File | What |
|---|---|
| `tippo-referral-tiers.js` | Standalone widget (no dependencies). Builds an SVG, drives the dots with `requestAnimationFrame`; every frame is a pure function of time, so it is seek-able. Picks the desktop or mobile layout from the container width (`< 480 px` → mobile) and switches live on resize. |
| `preview.html` | Both layouts with play / pause / restart and a scrubber. |
| `lottie/tippo-referral-tiers-desktop.json`, `lottie/…-mobile.json` | Same animation as Lottie (30 fps, 180 frames, seamless loop), generated by `../tippo-referral-tiers-animation-src/lottie.py`. No drop shadows (Lottie renderer support is partial). |

Sources: `../tippo-referral-tiers-animation-src/` — `lottie.py` (Lottie export), `capture.mjs` (renders preview frames with Playwright for QA).

## Embed

```html
<div id="referral-tiers" style="max-width:874px"></div>
<script src="tippo-referral-tiers.js"></script>
<script>
  const anim = TippoReferralTiers.mount(document.getElementById('referral-tiers'), {
    variant: 'auto',   // 'auto' | 'desktop' | 'mobile'
    autoplay: true,
    bg: '#FFFFFF',     // page background behind the graphic (halo around the dots)
  });
  // anim.play(); anim.pause(); anim.seek(2.5); anim.destroy();
</script>
```

The container keeps the layout's aspect ratio (`874 / 210` or `350 / 108`). Font: inherits
`"Non Bureau", Inter, system-ui` — load Non Bureau on the page. `prefers-reduced-motion: reduce`
shows the static scene without dots.

Lottie: `lottie.loadAnimation({ container, path: 'lottie/tippo-referral-tiers-desktop.json', loop: true })`.

## Dots (loop 6.0 s, same timing on both breakpoints)

Green dots, 8 px (mobile 7), with a background-coloured halo so they read on top of the arrow line.

| Dot | Route | Timing |
|---|---|---|
| **From You** | along arrow 1 from its start to its head (You → Tier 1), hidden while "under" Tier 1, then along arrow 2 from its start to its head (Tier 1 → Tier 2) | one every 1.5 s (4 per loop); arrow 1 leg 1.1 s, pause under Tier 1 0.2 s, arrow 2 leg 1.2 s |
| **From Tier 1** | along arrow 2 from its start to its head (Tier 1 → Tier 2) | one every 1.5 s, offset by 0.75 s from the You dots; 1.2 s |

Dots run only along the arrow lines (never across the nodes or labels). On every leg a dot appears smoothly
(scale 0 → 1 with ease-out plus opacity 0 → 1, 0.25 s) and disappears smoothly (scale 1 → 0 with ease-in plus
opacity 1 → 0 over the last 0.3 s), including the dive under Tier 1. Constant speed along each leg. The loop is seamless
(dots that are in flight at 6.0 s continue from 0.0 s).

## Mobile layout (350×108)

Horizontal, like desktop, with elements at ~0.7× desktop size so they stay legible: You 64 px, Tier 1 three
36 px avatars, Tier 2 ring 78 px; arrows 43.5 px with «INVITES» 9 px above; labels 14 px under each node.
